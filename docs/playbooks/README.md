# Playbooks

Generic, practical checklists distilled from the kind of work SiteCheckup supports: moving websites between hosts and platforms, hardening them, and keeping clients and developers aligned while doing so. Every scenario in them is invented (`example.com`, `*.test`); any resemblance to a real project is coincidence.

| Playbook | Use it when |
| --- | --- |
| [Site migration checklist](site-migration-checklist.md) | You are moving a site to a new host, platform or domain |
| [WordPress hardening](wordpress-hardening.md) | You inherit a WordPress site or need a prioritised fix list that maps to `audit` check IDs |
| [Responding to a pentest report](responding-to-a-pentest-report.md) | A report just landed and you need to triage, assign and retest |
| [Working with clients and developers](working-with-clients-and-developers.md) | You translate between the people who own the business risk and the people who fix it |
