# Examples

Generated by `make report` (`scripts/generate_examples.py`) against the demo lab, which contains only invented content. The lab was served by the Docker images in `docker-compose.yml` (`nginx:1.27-alpine`, plus `wordpress:6-apache` for the WordPress sample), so the `Server` header versions reflect those images at generation time.

| File | What it is |
| --- | --- |
| [`audit-report.html`](audit-report.html) | Self-contained HTML audit of the legacy site (open it in a browser) |
| [`audit-report.json`](audit-report.json), [`audit-report.md`](audit-report.md) | Same audit as JSON and Markdown |
| [`audit-terminal.svg`](audit-terminal.svg) | Terminal screenshot used in the README (rich `save_svg`) |
| [`compare-report.html`](compare-report.html), [`.json`](compare-report.json), [`.md`](compare-report.md) | Legacy -> new comparison with `--path-map demo/path-map.csv` |
| [`compare-results.csv`](compare-results.csv) | One row per compared URL |
| [`compare-terminal.svg`](compare-terminal.svg) | Terminal view of the comparison |
| [`audit-wordpress-report.md`](audit-wordpress-report.md) | Audit of a default WordPress install from the optional `wordpress` profile (after the five-minute install) |

Regenerate with:

```bash
docker compose up -d legacy-site new-site     # or: make demo-local
make report
# with the optional WordPress profile running and installed:
make report REPORT_ARGS='--wordpress http://localhost:8082'
```
